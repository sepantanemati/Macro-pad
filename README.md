The Macro Pad:

A macro pad is a compact, standalone auxiliary keypad in which each key can be programmed to execute shortcuts, launch applications, or perform multi-step automated commands with a single press.

My primary goal with this macro pad is to enable shortcut activation with a single click.

Components Used:
- Transparent Blue Axis Switch with Puller, 3-Pin Keyboard Switches
- Raspberry Pi Pico
- Keycaps (3D printed)

The PCB is designed using KiCad.

This project is developed for https://halflife.hackclub.com/
